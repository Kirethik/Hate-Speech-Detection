# Raw Datasets Directory

This folder holds unedited raw data downloaded from benchmark sources.
Do not commit raw dataset files to version control.

## Supported Data Sources

1. **HateXplain** — Multilingual word-level rationales and target groups.
   - HuggingFace: `hatexplain`
2. **DynaHate** — Dynamically generated human-and-model-in-the-loop hate speech.
   - HuggingFace: `facebook/dynahate`
3. **HASOC (2019-2021)** — Hate Speech and Offensive Content in Indo-Aryan and Dravidian languages.
   - Website: https://hasocfire.github.io/
4. **MACD** — Multi-Aspect Code-Mixed Dravidian dataset (Tamil, Telugu, Kannada, Malayalam).
5. **DravidianCodeMix** — YouTube comments in code-mixed Dravidian languages.
6. **RUHSOLD** — Roman Urdu Hate Speech and Offensive Language Dataset.
7. **HateCheck** — Diagnostic test suite of 29 functional categories with contrastive pairs.
8. **ParaDetox & CONAN** — Parallel detoxification and counter-narrative paired datasets for Model B.
